# 도메인 용어 사전

Backend, frontend와 사용자 표현에서 공유하는 용어의 팀 검토용 초안이다. 용어명은 클래스나 패키지 구조를 지정하지 않는다.

## 계정과 인증


| 용어                              | 의미                                      |
| ------------------------------- | --------------------------------------- |
| 계정 · `account`                  | 개인 일정과 할 일을 소유하고 그룹에 참여하는 Calio 사용 주체다. |
| 게스트 계정 · `guest-account`        | 게스트 인증으로 생성하는 Calio 계정이다.               |
| 계정 인증 토큰 · `account-auth-token` | Calio API에서 요청자의 계정을 인증하는 Bearer 토큰이다.  |


## 일정


| 용어                        | 의미                                                                                 |
| ------------------------- | ---------------------------------------------------------------------------------- |
| 일정 · `event`              | 캘린더에 표시하는 일정 단위로, 단건 일정과 반복 회차를 포함한다.                                              |
| Calio 일정 · `calio-event`  | Calio DB에 저장된 내부 일정으로, Google에서 가져와 저장한 일정도 포함하며 Google Calendar의 외부 일정 데이터와 구분한다. |
| 개인 일정 · `personal-event`  | 개인 계정에 속한 일정으로, 그룹에 직접 생성한 일정과 구분한다.                                               |
| 단건 일정 · `single-event`    | 반복 시리즈에 속하지 않고 하나의 시작·종료 구간을 가진 일정이다.                                              |
| 종일 일정 · `all-day-event`   | 특정 시각이 아니라 날짜 전체를 차지하며, 종료값은 마지막 포함 날짜 다음 날의 자정이다.                                 |
| 중요 일정 · `important-event` | 사용자가 중요 표시를 한 개인 일정이다.                                                             |


## 반복 일정


| 용어                                        | 의미                                          |
| ----------------------------------------- | ------------------------------------------- |
| 반복 일정 시리즈 · `recurrence-event`            | 첫 회차의 시간 정보와 반복 규칙으로 여러 회차를 생성하는 일정이다.      |
| 반복 회차 · `recurrence-occurrence`           | 반복 시리즈의 개별 일정으로, 시리즈 ID와 원래 시작값의 조합으로 구분한다. |
| 반복 회차 개별 변경 · `recurrence-event-override` | 특정 회차의 시간·내용을 변경하거나 그 회차를 제외한 기록이다.         |
| 반복 규칙 · `recurrence-rule`                 | 반복 시리즈에 포함되는 회차들을 계산하는 규칙이다.                |
| 반복 주기 · `recurrence-frequency`            | 매일·매주·매월·매년 등 반복의 기본 간격으로, 반복 규칙의 일부다.      |


## 시간과 조회 범위


| 용어                    | 의미                                                    |
| --------------------- | ----------------------------------------------------- |
| 일정 시간 정보 · `schedule` | 일정의 시작값, 종료값, 종일 여부와 시간대를 묶은 정보다.                     |
| 일정 시간대 · `time-zone`  | 일정의 현지 시각을 해석하는 시간대로, 기기의 표시 시간대와 구분한다.               |
| 조회 범위 · `query-range` | 데이터를 찾는 구간으로, 일정 시간 조회는 종료 경계를 제외하고 날짜 조회는 양 끝을 포함한다. |


## 태그


| 용어                    | 의미                                     |
| --------------------- | -------------------------------------- |
| 태그 · `tag`            | 일정의 분류와 표시 색상을 정하는 항목이다.               |
| 기본 태그 · `default-tag` | 기본 제공하는 태그로, 개인 기본 태그와 그룹 기본 태그를 구분한다. |
| 커스텀 태그 · `custom-tag` | 사용자가 생성·수정하는 개인 또는 그룹의 태그다.            |
| 색상 코드 · `color-code`  | 태그의 표시 색상을 나타내는 `#RRGGBB` 형식의 값이다.     |


## 그룹과 공유


| 용어                                   | 의미                                                                      |
| ------------------------------------ | ----------------------------------------------------------------------- |
| 그룹 공간 · `group-space`                | 여러 계정이 구성원으로 참여하여 일정을 함께 다루는 공간이다.                                      |
| 그룹 구성원 · `group-member`              | 특정 계정의 그룹 참여 기록으로, 구성원 ID와 계정 ID를 구분한다.                                 |
| 그룹 참여 정보 · `group-membership`        | 구성원의 역할, 참여 상태와 설정 등 그룹 참여 관계의 속성이다.                                    |
| 그룹 소유자 · `group-owner`               | 그룹의 소유권을 가진 계정이며, 그룹 내 역할은 `OWNER`다.                                    |
| 그룹 참여 상태 · `group-member-status`     | 참여 중(`ACTIVE`), 자진 탈퇴(`LEFT`), 내보내짐(`REMOVED`)을 나타낸다.                   |
| 그룹 초대 · `group-invitation`           | 링크나 코드를 통해 특정 그룹에 참여하도록 하는 초대다.                                         |
| 그룹 참여 결과 · `group-join-result`       | 신규 참여(`JOINED`), 기존 참여(`ALREADY_MEMBER`), 재참여(`REJOINED`)를 구분하는 처리 결과다. |
| 그룹 캘린더 · `group-calendar`            | 특정 그룹 공간의 일정을 조회·표시하는 캘린더다.                                             |
| 그룹 일정 · `group-event`                | 개인 일정의 공유가 아니라 그룹 공간에 직접 생성한 일정이다.                                      |
| 개인 일정 그룹 공유 · `personal-group-share` | 개인 일정 또는 반복 시리즈를 공유 대상 그룹과 연결하는 관계다.                                    |
| 익명 공유 설정 · `anonymous-sharing`       | 그룹 구성원의 공유 익명 여부 설정으로, 숨길 정보와 적용 범위는 팀 검토가 필요하다.                        |


## 할 일과 공휴일


| 용어              | 의미                                     |
| --------------- | -------------------------------------- |
| 할 일 · `task`    | 개인 계정에 속하며 완료 여부를 관리하는 항목이다.           |
| 공휴일 · `holiday` | 날짜와 이름으로 관리하는 공휴일 정보로, 개인 종일 일정과 구분한다. |


## 일정 조율 투표


| 용어                          | 의미                                              |
| --------------------------- | ----------------------------------------------- |
| 투표방 · `vote-room`           | 후보 날짜별로 참여할 수 없는 날짜를 모아 일정을 조율하는 공간이다.          |
| 투표 참여자 · `vote-participant` | 투표방에서 닉네임으로 구분하는 참여자로, Calio 계정이나 그룹 구성원과 구분한다. |
| 불가능한 날짜 선택 기록 · `vote`      | 참여자가 제출한 불가능한 날짜 한 건으로, 가능한 날짜에 대한 찬성표가 아니다.    |
| 투표 결과 · `vote-result`       | 제출자들이 불가능하다고 선택한 날짜별 인원과 닉네임을 집계한 결과다.          |


## AI 캘린더 대화


| 용어                                | 의미                                                                               |
| --------------------------------- | -------------------------------------------------------------------------------- |
| 대화 · `chat`                       | 한 계정이 AI 캘린더 도우미와 이어가는 여러 메시지의 묶음이다.                                             |
| 메시지 · `message`                   | 대화에 기록하는 사용자 또는 도우미의 발화 한 건이다.                                                   |
| 구조화된 대화 결과 · `chat-result-block`  | 자연어 응답과 별도로 JSON 블록 형식으로 전달하는 일정 목록, 빈 시간 또는 일정 변경 제안이다.                         |
| 빈 시간 · `free-time`                | 검색 조건을 만족하고 시간을 가진 일정과 겹치지 않는 구간으로, 종일 일정 안내는 별도로 확인한다.                          |
| 일정 변경 제안 · `event-change-preview` | 저장 전에 일정의 생성·수정·삭제 내용을 보여주는 제안으로, 제안 자체는 일정을 변경하지 않는다.                           |
| 일정 변경 종류 · `event-change-type`    | 생성(`CREATE`), 수정(`UPDATE`), 삭제(`DELETE`) 중 어떤 변경인지 나타낸다.                         |
| 일정 변경 범위 · `event-change-scope`   | 단건 일정(`EVENT`), 회차 하나(`THIS_OCCURRENCE`), 시리즈 전체(`ENTIRE_SERIES`) 중 변경 대상을 나타낸다. |


## Google Calendar 연동


| 용어                                              | 의미                                                  |
| ----------------------------------------------- | --------------------------------------------------- |
| Google Calendar 연결 · `google-event-integration` | Calio 계정에 Google 캘린더 접근 권한을 연결한 상태로, 동기화 완료와 구분한다.  |
| Google 일정 · `google-event`                      | Google Calendar의 외부 일정으로, Calio 내부 일정과 식별자를 구분한다.   |
| Google 일정 대응 관계 · `google-event-mapping`        | Google의 외부 일정과 Calio의 내부 일정·시리즈·회차 변경 기록을 연결하는 관계다. |
| Google 일정 동기화 · `google-event-sync`             | Google의 일정 데이터를 조회하여 Calio 내부 일정에 반영하는 처리다.         |
| Google 연동 작업 · `google-operation-job`           | Google 연동에서 실행할 작업의 순서, 처리 상태와 재시도를 관리하는 단위다.       |
